# Homework Calendar

The app lives in [`lesson-calendar`](./lesson-calendar).

It is deployed at [glittery-blini-4c6ea4.netlify.app](https://glittery-blini-4c6ea4.netlify.app) and uses a Netlify Functions OAuth backend so a Google Calendar connection can survive page reloads and browser restarts.

See [`lesson-calendar/README.md`](./lesson-calendar/README.md) for Google Cloud, Netlify environment-variable, local-development, and deployment setup.
